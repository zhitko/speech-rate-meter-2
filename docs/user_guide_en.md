# Speech Rate Meter 2

Speech Rate Meter 2 records speech from the microphone and stores each take as a WAV file on this device.

## Record

1. Open **Home**.
2. Tap the microphone button and speak.
3. Tap the button again to stop. If **Auto Stop Recording** is on, recording also ends after a stretch of silence.
4. Tap **Play** to hear the file that was just saved.

Saved files are kept in the application's private `data/records` folder. They are not uploaded.

## Settings

**Settings** holds language, theme, color, font size, and the navigation bar.

The **Recording** section controls voice-activity detection: auto-stop, calibration, the detection method, and the silence and threshold values used while recording.

**Delete user data** removes the saved recordings. It does not change these settings.
