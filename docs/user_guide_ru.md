# Измеритель темпа речи 2

«Измеритель темпа речи 2» записывает речь с микрофона и сохраняет каждую попытку в файл WAV на этом устройстве.

## Запись

1. Откройте **Главная**.
2. Нажмите кнопку микрофона и говорите.
3. Нажмите кнопку ещё раз, чтобы остановить запись. Если включена **Автоостановка записи**, запись также завершится после паузы.
4. Нажмите **Воспроизвести**, чтобы прослушать только что сохранённый файл.

Файлы хранятся в закрытой папке приложения `data/records`. Они никуда не отправляются.

## Настройки

В **Настройках** задаются язык, тема, цвет, размер шрифта и нижняя панель навигации.

Раздел **Запись** управляет обнаружением речи: автоостановкой, калибровкой, методом детектора, длительностью тишины и порогами.

**Удалить данные пользователя** стирает сохранённые записи. Сами настройки при этом не меняются.
